Quero redirecionar a investigação. Meu objetivo é identificar uma oportunidade para um projeto open source independente, possivelmente em Rust, útil em infraestrutura financeira, blockchain ou execução de ações por agentes.
Procure até três problemas técnicos recorrentes que hoje exigem código próprio, investigação manual ou compromissos relevantes entre segurança, desempenho e complexidade. Considere execução em produção e testes de falhas.
Para cada problema, explique:
1. Um cenário concreto que o reproduza, usando apenas informações compartilháveis e exemplos anonimizados.
2. A frequência e o impacto observados, separando evidência de estimativa.
3. Como ele é resolvido hoje e o que continua difícil.
4. Quais ferramentas existentes já cobrem esse caso e qual lacuna sobra.
5. O menor experimento reproduzível que permitiria medir uma melhoria, com uma referência de comparação e critérios de correção.
Algumas hipóteses para investigar são recuperação após respostas perdidas, testes determinísticos de integrações, limites compartilhados entre executores e reconciliação de eventos. Pode descartá-las se a evidência apontar para problemas melhores.
Avalie também se Rust traria uma vantagem mensurável. A conclusão pode ser contribuir para uma ferramenta existente. Priorize um problema demonstrável que uma equipe teria motivo concreto para adotar.
